# Security

These plugins run locally and may inspect or modify files when a user authorizes a task. Review a plugin's skill and scripts before enabling it.

Do not include secrets, credentials, private project data, or personal messages in bug reports. Report a vulnerability through a [private security advisory](https://github.com/anon5376/codex-agent-plugins/security/advisories/new).

Agent Bus Dashboard binds to loopback by default and has no built-in sign-in. Do not expose it to a network without placing authentication and transport security in front of it.
